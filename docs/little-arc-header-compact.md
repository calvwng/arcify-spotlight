# Compact Little Arc header

This presentation-only candidate layers on the native-tested Little Arc/shared Today pair, including the external-message namespace correction. It is not installed in the everyday profile.

The default header shows Temporary, a Space selector, Review Open in [Space], Collapse and More…. Review still prepares a destination and opens the existing trusted control tab; only that tab's final confirmation transfers the exact native page. A proposed Space is not committed membership.

More… reveals the window selector, Refresh choices and Trusted controls. Window 1, Window 2 and so on distinguish the current choices without displaying raw native IDs or page titles. Their private option values retain the exact native window identity. Numbers are display labels, not persistent window names, and may change when choices refresh. A suggested choice is marked. When no proposed window survives, the advanced choices open automatically and review remains disabled until the user explicitly chooses a valid destination.

Collapse leaves Show Little Arc controls. Reopening retains the current advanced disclosure state. Status and critical errors remain outside the advanced area; a critical error reveals a collapsed header. The advanced Refresh choices path remains available after a stale-context error. No recovery records, authentication, authority token, final confirmation, transfer or permission behavior changes. A bounded boolean presentation hint adjusts the injected frame's height only.

Checks cover production markup, repeated disclosure toggles, focus, dismissal/reopen, missing/stale destinations, errors, compact/advanced sizing and the existing controller path. Native screenshots use synthetic pages. Prior browser-session restoration, native OS context-menu/physical Escape, real screen-reader and interrupted-process recovery release gates are not resolved by this presentation change.
