Arcify Spotlight

Connect to Arcify

Pair Spotlight with your Arcify sidebar to search its spaces and saved tabs.

Pair both extensions

  1. Open chrome://extensions and enable Developer mode to see extension IDs.
  2. Copy the ID for Arcify and paste it into the Arcify extension ID field below.
  3. Open Arcify’s connection settings and save this Spotlight extension ID there too.
  4. Return here and select Save and check connection.

Unpacked extensions can have different IDs when loaded from different folders. Check both IDs again if you move either extension.

Copy this ID into Arcify’s connection settings.

Connection

Use the 32-letter ID shown for Arcify. Leave this empty to disable the connection.

Disabled

The connection is disabled until you pair both extensions.

Pairing is optional and disabled by default. Your chosen ID is stored locally in this browser. Disconnecting stops Spotlight from requesting Arcify data; you can also clear the Spotlight ID in Arcify’s settings.
