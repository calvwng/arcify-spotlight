Spotlight settings

Choose appearance and link behavior, and optionally connect Spotlight to your Arcify sidebar.

Appearance

System follows your device’s light or dark setting automatically. Your choice is saved for this options page.

Shift-click links

Off by default. Pair both extensions, then Shift-click an ordinary link in the main webpage. Little Arc opens one real browser page; its header can move that same page into a Space. Sidebar selection keeps its existing behavior.

For Shift-click and Peek openings. Returning to the source, changing tabs (including Little Arc settings), or leaving Little Arc clears dimming until a new opening. It also expires after ten minutes. Other opening routes are unchanged.

Optional Peek previews can be blocked by websites or sign-in requirements. Its explicit Little Arc fallback remains available. Opening actions use the verified current preview URL, or the original link when unavailable; form entries, JavaScript state and history are not transferred.

Subframe links, named targets and pages that intercept clicks may need the Little Arc context menu. A webpage can cover or interfere with embedded controls. No security headers are bypassed.

Pair both extensions

Each extension must save the other’s ID. You can start on either side; both saves are needed before the connection is ready.

  1. Open chrome://extensions and enable Developer mode to see extension IDs.
  2. Copy the ID for Arcify, paste it below, and select Save Arcify ID. Awaiting Arcify approval means this save worked and pairing still needs the next step.
  3. Copy this Spotlight extension ID below. Open Arcify’s connection settings, paste it into the Spotlight extension ID field, and save it there too.
  4. Return here and select Refresh status. Once both IDs are saved correctly, the status should be Connected.

Unpacked extensions can have different IDs when loaded from different folders. Check both IDs again if you move either extension.

Save this ID in Arcify’s connection settings, even if you already saved Arcify’s ID here.

Connection

Use the 32-letter ID shown for Arcify. Saving also checks the connection; you can finish pairing on the other side afterward. Leave this empty to disable the connection.
